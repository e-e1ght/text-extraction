# AI 채팅 txt 추출기

AI 채팅 사이트의 대화 내역을 txt 파일로 저장하는 크롬 확장 프로그램입니다.
각 사이트와 관련 없는 **개인 백업용 비공식 도구**입니다.

## 지원 사이트

- 케이브덕 (caveduck.io)
- 로판 AI (rofan.ai)
- 티팟 (teapotchat.com)
- 엘린 (elyn.ai)
- 크랙 (crack.wrtn.ai)
- 유니챗 (univers.chat)

## 지원 브라우저

- 크롬
- 웨일

## 설치

1. 이 저장소를 받습니다.
   - git: `git clone https://github.com/e-e1ght/text-extraction.git`
   - 또는 **Code → Download ZIP**으로 받은 뒤 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다. (웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 받은 폴더를 선택합니다.

> 압축을 푼 폴더는 지우거나 옮기면 안 됩니다. 확장 프로그램이 그 폴더에서 실행됩니다.

## 사용법

1. 지원 사이트의 대화방을 엽니다.
2. 툴바의 확장 아이콘을 누르면 화면 오른쪽 위에 패널이 열립니다.
3. **이 대화방 추출하기**를 누르면 다운로드 폴더에 `캐릭터이름_날짜.txt`가 저장됩니다.

## 업데이트

GitHub에 새 버전이 올라오면 툴바 아이콘에 `NEW` 배지가 붙고, 패널 위쪽에 안내와 GitHub 링크가 표시됩니다. (하루 한 번, 그리고 패널을 열 때 확인합니다. 자동으로 설치되지는 않습니다.)

- git으로 받았다면 폴더에서 `git pull`을 실행합니다.
- ZIP으로 받았다면 새 ZIP을 받아 **처음 설치한 폴더에 그대로 덮어씁니다.**
  새 폴더에 풀어서 따로 불러오면 브라우저가 다른 확장으로 인식해, 저장해 둔 이름·옵션이 사라지고 같은 확장이 두 개가 됩니다.

그다음 확장 프로그램 페이지에서 이 확장의 **새로고침(↻)** 버튼을 누릅니다.

## 개인정보

- 대화 내용은 **내 컴퓨터에 txt로만 저장**되며, 다른 곳으로 보내지 않습니다.
- 대화를 불러오기 위해, 지금 열려 있는 사이트의 로그인 정보(쿠키 또는 사이트가 브라우저에 저장해 둔 로그인 토큰)를 읽어 **그 사이트의 서버에만** 보냅니다. 사이트 화면이 대화를 불러올 때 하는 요청과 같습니다.
  - 티팟: Firebase 로그인 토큰 → 티팟의 Firestore 서버
  - 엘린: `elyn-access-token` 쿠키 → api.elyn.ai
  - 크랙: `access_token` 쿠키 → crack-api.wrtn.ai
  - 케이브덕 · 로판 AI · 유니챗: 사이트의 로그인 쿠키를 그대로 사용
- 그 밖에 외부로 나가는 요청은 두 가지뿐입니다.
  - 새 버전 확인: GitHub의 `manifest.json` 읽기 (raw.githubusercontent.com)
  - 패널 글꼴: 프리젠테이션 웹폰트 받기 (cdn.jsdelivr.net)
- 패널에 입력한 내 이름과 옵션은 브라우저 안(`chrome.storage.local`)에만 저장됩니다.

## 주의사항

- **개발자 모드 경고:** 브라우저를 켤 때 "개발자 모드 확장 프로그램 사용 중지" 같은 안내가 뜰 수 있습니다. 직접 설치한 확장이라 뜨는 것이므로 **닫기**(또는 X)를 누르면 됩니다. "사용 중지"를 누르면 확장이 꺼집니다.
- **비공식 도구:** 각 사이트의 공식 기능이 아닙니다. 사이트 구조가 바뀌면 갑자기 추출이 안 될 수 있습니다.
- 대화가 아주 길면 불러오는 데 시간이 걸릴 수 있습니다. 사이트에 부담을 주지 않도록 일부러 조금씩 나눠 받습니다.
- 사용에 따른 책임은 사용자에게 있습니다. 각 사이트의 이용 약관을 확인하고 개인 백업 용도로만 사용하시기 바랍니다.

## 새 사이트 추가하기 (개발용)

1. `adapters/`에 사이트용 파일을 추가하고 `registerChatAdapter({...})`로 등록합니다. 형식은 `adapters/registry.js` 주석에 있습니다.
2. `manifest.json`의 `host_permissions`와 `content_scripts.matches`에 도메인을 추가합니다.
3. `manifest.json`의 `content_scripts.js`와 `background.js`의 `CONTENT_FILES`에 새 파일을 추가합니다.
